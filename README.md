# NTP Audit

ระบบภายในสำหรับข้อมูลเงินเดือนพนักงาน นำเข้า Excel รายเดือน และรายงานรายปี

## เริ่มใช้งานหน้าจอต้นแบบ

```bash
npm install
npm run dev
```

เปิด `http://localhost:3000` และเริ่มที่ `/login` หรือ `/` ในขั้นนี้ทุกหน้าใช้ข้อมูลพนักงานสมมติ และขั้นตอนนำเข้ายังไม่บันทึกไฟล์

## โครงสร้าง

- `src/app` — Next.js routes และระบบภาพ
- `src/components/workspace.tsx` — หน้าจอและการไหลของงาน
- `src/lib/mock.ts` — ข้อมูลสมมติและยอดตัวอย่างในหน่วยสตางค์
- `docs/product-plan.md` — แผน session, ระบบข้อมูล และเกณฑ์ตรวจ

ไฟล์ `.xlsx` และ `.env*` ถูกกันออกจาก Git เพื่อป้องกันการเผยแพร่ข้อมูลส่วนบุคคลและคีย์เชื่อมต่อ

## สถานะงาน

Session 1: หน้าจอ 17 เส้นทางสำหรับตรวจแบบและข้อมูลสมมติ

Session ถัดไป: persistence, authentication, Excel importer, รายงานจากฐานข้อมูล และการส่งออก
